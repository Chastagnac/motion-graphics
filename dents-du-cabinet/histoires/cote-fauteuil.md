# Côté fauteuil : les histoires

Ce fichier ne contient que l'écriture. Pas de pose, pas de décor dessiné, pas de mise en page :
ça se règle après, une fois le texte validé.

Comment lire et corriger :

- Un titre `##` par histoire, puis la couleur de série, le lieu et la légende du post.
- `La description : …` est la petite phrase qui accompagne le post sur Instagram, au-dessus de la
  légende. Une seule phrase, drôle, sans raconter la chute.
- Une **Page** = une image du carrousel. Une ligne = une case (1 à 4 cases par page).
- `NOM : réplique` pour une bulle, `(narration) texte` pour un cartouche.
- Une réplique tient en 8 mots environ.
- Personnages : docteure, docteur, collaborateur, assistante, incisive (accueil), canine (assistante),
  molaire (cheffe), lait (le patient), sagesse (invitée).

Construction visée pour chaque histoire : une ouverture, deux ou trois relances qui font monter la
situation, une première chute, puis un dernier rebond sur la page finale.
